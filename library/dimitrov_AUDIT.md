# Dimitrov, square-free and cube-free values of [n^c tan^θ(log n)]: certification audit note

Instances: `dimitrov_squarefree.json`, `dimitrov_squarefree_lowc.json`, `dimitrov_cubefree.json`, `dimitrov_cubefree_lowc.json`, all level mode. Sources: S. I. Dimitrov, "Square-free values of [n^c tan^θ(log n)]," Springer Optim. Appl. 207 (2023), 33-43, and S. I. Dimitrov, "Pairs of cube-free values of the type [n^c tan^θ(log n)], [n^c tan^θ(log n)] + 1" (2025). Both prove `S_c(x) >> x` for `1 < c < 3/2` with `θ > 1` fixed. All four certificates pass, 25 slices in total.

## Structural verdict

These are the cleanest instances in the census so far, and for a specific reason: neither paper uses an exponent pair. The only exponential-sum input is Lemma 2, which is Graham-Kolesnik Theorem 2.9, the van der Corput derivative test of integer order q. Consequently there is no bilinear scope boundary of the kind that forced a pinned exponent pair in the Heath-Brown and Guo-Guo-Lu instances. Nothing is pinned here and the transcription is exact.

The reason the system is affine at all is worth isolating. Every application of Lemma 2 in either paper has `F ~ h x` exactly, because the implicit function satisfies `y' ~ K^{γ-1} d^{2γ}` with `K ~ x^c d^{-2}`, so `K^γ d^{2γ} ~ x`. The same identity holds in the cube-free paper with `L ~ x^c t^{-3}`. This is also why the decoration `tan^θ(log n)` never enters the arithmetic: the range `[Δ₁, Δ₂)` of (3) and (4) is chosen so that `tan(log n)` lies in `[1, 2]`, and the factor is bounded above and below throughout.

Both instances are min-max in the manner of `cao_zhai.json`. Variables are `(θ, ζ, η)` with `ζ = log_x z` the divisor-split exponent and `η` the Vaaler truncation exponent, `H = x^η/d` in the square-free paper and `x^η/(dt)` in the cube-free one. The paper pins `ζ = η = (2c-1)/4`. Both are freed here, so the certificate tests those choices rather than inheriting them. The theorem's conclusion is exactly the statement `θ*(c) < 1`.

## Findings

**Finding 1 (the hypothesis is exactly the toolkit's ceiling).** Both papers declare `1 < c < 3/2` as a standing hypothesis in their Notations section and never derive it. It is nevertheless exact. The certified profiles are piecewise linear with one breakpoint each:

- square-free: `θ*(c) = (c+3)/5` on `(1, 16/13]`, binding set {tail, h_average, vdC_q0_via_S9}, then `θ*(c) = (4c+1)/7` on `[16/13, 3/2)`, binding set {tail, h_average, vdC_q1};
- cube-free: `θ*(c) = (c+3)/5` on `(1, 7/6]`, same binding set, then `θ*(c) = (2c+1)/4` on `[7/6, 3/2)`, binding set {tail, h_average, vdC_q0}.

Both reach `θ* = 1` exactly at `c = 3/2` and nowhere below it. So the assumed range is the true feasibility boundary of the stated toolkit, and 3/2 is a genuine facet rather than a convenient stopping point. This is a category the census has not recorded before. Heath-Brown's Lemma 9 conditions and seven of Guo-Guo-Lu's nine were slack or vacuous, whereas here an assumption that was never argued for turns out to be sharp.

**Finding 2 (the derivative-test orders are optimal).** Lemma 2's order q is a design parameter in the sense that `l = 5` is one in Rivat-Sargos, since changing it changes which terms exist. Optimizing over it by hand: the square-free paper uses `q = 1` for S⁽⁷⁾ and S⁽⁸⁾ and `q = 0` for S⁽⁹⁾, which gives the ceiling 3/2, while `q₁ = 2` gives only `14/11` and `q₁ = 3` only `15/13`. The order `q₁ = 0` also reaches 3/2, by a different route: its d-sum diverges and contributes `z^{1/2}`, turning the constraint into `ζ + η < 1`. The cube-free paper uses `q = 0` throughout, which is forced. Taking `q₁ = 1` there gives only `11/9`, because the inner sum runs over the t-progression alone and the d-sum contributes `z^{5/6}`. Both papers therefore make the best available choice.

**Finding 3 (the design point is optimal in one paper and not the other).** The optimizer sets `ζ = η` in both, so the paper's coupling `H = z/d` is derived rather than assumed. The common value is where the papers differ. For the cube-free paper the optimum on `[7/6, 3/2)` is `ζ = η = (2c-1)/4`, which is exactly the paper's own choice, so it is optimal. For the square-free paper the optimum on `[16/13, 3/2)` is `ζ = η = (3c-1)/7`, giving `θ* = (4c+1)/7`, whereas the paper's `(2c-1)/4` gives `(2c+1)/4`. The paper's value is strictly worse for every `c < 3/2` and the two agree only at the endpoint. Theorem 1 is unaffected, since both are below 1 on the same range and the theorem claims only a lower bound. The observation is that `(2c+1)/4` is precisely Rieger's 1978 error exponent for `[n^c]`, so the design point appears to have been inherited from the model proof rather than optimized for this one, and the same argument already yields the better exponent.

**Finding 4 (an invalid absorption in the cube-free paper, harmless).** Display (38) absorbs the third term `x^{c-1} H^{-1} t^{-3} log²x` into the first term `x^c H^{-1} d^{-3} t^{-3}`. That requires `d³ <= x`, that is `ζ <= 1/3`, which fails at the paper's own `ζ = (2c-1)/4` for every `c > 7/6`, hence on most of the claimed range. Carried properly the term is `x^{c-1-η} d t^{-2}`, and the d-sum diverges: `Σ_{dt<=z} d t^{-2} ~ z²`, giving the exponent `c - 1 + 2ζ - η`. It is retained as row 4 of the cube-free instance and it never binds on the interior, being tight only at `c = 3/2`. Neither the threshold nor the profile changes anywhere. The diagnosis is clean: the identical step is valid in the square-free paper, where the ratio is `x^{-1} log H`, because there `K ~ x^c d^{-2}` carries the `d²` that the cube-free `L ~ x^c t^{-3}` does not, the inner sum having been reduced to the t-progression only.

**Finding 5 (census placement).** The value 3/2 is Rieger's 1978 threshold for square-free `[n^c]`. The corresponding `[n^c]` results are a generation ahead, at `149/87 = 1.7126` for square-free (Cao-Zhai 2008, whose 1998 predecessor is already transcribed here as `cao_zhai.json`) and `31/17 = 1.8235` for cube-free, both cited by Dimitrov himself. Whether the decoration costs that gap is a testable question rather than an obvious one. The derivative tests transfer verbatim, since Lemma 2 asks only for `|f^{(r)}| ≍ F N^{-r}` and the implicit function supplies it. What may not transfer is the spacing and large-sieve machinery the modern arguments rely on, which wants monomial phases, whereas the phase here is an implicit function of `t = y^c tan^θ(log y)`. Mapping that boundary is the natural follow-up, and the comparison instance is already in the repository.

## Mutation results

Square-free: 12 of 36 killed. Cube-free: 16 of 40. The survivor structure is fully explained by the geometry and is uniform across both.

The four inactive box rows in each instance (`ζ >= 0`, `η >= 0`, `ζ <= zmax·c`, `η <= c`) survive all sixteen perturbations, as they should, since none is active at the optimum. The `ζ <= η` row and the two lower-bound term rows survive loosening and die under tightening, which is the signature of a constraint that is tight but one-sided at the optimum. Loosening `θ >= c - ζ` while `ζ <= η` still holds simply transfers the binding role to `θ >= c - η`, leaving the profile untouched, whereas tightening either one raises it immediately.

The one real difference between the two papers shows up here. In the square-free instance the tail row survives loosening, because `ζ` appears in no other term and the optimizer can absorb the slack. In the cube-free instance the same row dies in all four directions, because `ζ` also appears in the `z^{1/2}` loss of `vdC_q0`, making it a genuine trade-off variable rather than a free one. The retained `dropped_third` row survives loosening and dies under tightening, consistent with its being tight only at `c = 3/2`.
